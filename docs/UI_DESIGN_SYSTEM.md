# VASA design system

Deep green #07372D; dark text #173D31; warm cream #FFFCF6; white surfaces;
success #29845C; peach #FBE6D9; borders #DFE7DE. System/Inter-like sans-serif on
all forms, navigation, tables and small text. Readable Georgia-like editorial
serif on marketing display headings only. Pill buttons, 16–24px card radii,
visible keyboard focus, 44px targets, labeled inputs, aria-live statuses.

Workspace section navigation wraps accessibly on mobile; tables scroll within containers,
not the page. No external fonts/scripts, inline JS or weakening CSP. Use textContent
for API data. Marketing illustrations are explicitly examples; operational status
uses actual authorized APIs. No fabricated plan prices or working-billing claims.
