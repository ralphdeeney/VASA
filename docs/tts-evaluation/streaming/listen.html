Conversational TTS listening review

Download this directory and open this page locally. The samples use the same text at 16 kHz mono PCM16. Playback samples include measured generation gaps. No human listening preference has yet been recorded.

Score each voice from 1 to 5 for naturalness, intelligibility, timing and boundary continuity. Listen for skipped words, rushed delivery, unnatural sentence endings, clicks and audible pauses. Review all three texts; a short acknowledgment alone does not establish conversational quality.
